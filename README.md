### Creating the Tag on GitHub

Run the following commands in your local Git repository:

```bash
# Tag the current commit with valid SemVer tag
git tag -a v1.0.0 -m "Release v1.0.0 - Remix Rai MK Download Manager"

# Push the tag to your remote GitHub repository
git push origin v1.0.0
```

Or on GitHub:
1. Navigate to your repository page on GitHub.
2. Click **Releases** on the right sidebar -> **Draft a new release**.
3. In **Choose a tag**, enter `v1.0.0` and click **Create new tag: v1.0.0 on publish**.
4. Set release title to `v1.0.0 - Production Release`.
5. Click **Publish release**.

## ✨ Features

- **Turbo Multi-Segment Accelerator:** Dynamic chunk threads visualizer simulating up to 32 parallel download streams.
- **RGB Breathing Chassis:** Customizable RGB aura effects with Cyber Neon, Aurora Borealis, and Violet Pulse presets, complete with adjustable pulse rates.
- **Offline Media Viewer:** Embedded in-app previewer for downloaded videos, music, images, and text documents.
- **AES-256 Encryption Vault:** Lock sensitive downloads behind a secure passphrase vault with status indicators.
- **Smart URL Link Sniffer:** Automatic clipboard and link protocol detection for direct files, YouTube streams, and magnet URIs.
- **Cloud Account Sync:** Simulated cloud storage synchronization with Google Drive, Dropbox, and OneDrive.
